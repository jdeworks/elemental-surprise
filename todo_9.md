# Todo 9: Fix Recipe Reasoning Text

## Problem
Recipe reasonings (shown in the Recipes Modal) are often nonsensical or unfunny. They should be educational and witty.

## Current State
- Reasonings are generated by `scripts/expand-recipes.ts`
- Stored in recipe bucket files alongside results
- Displayed in the Recipes Modal with italic styling at 55% opacity
- Retrieved via `getRecipeReasoning(key)` from `src/data/loader.ts`

## Approach

### Step 1: Audit bad reasonings
Play the game and collect examples of bad reasonings. Also write a script to dump all reasonings for review:

```bash
# scripts/audit-reasonings.ts
# Load all recipes, output: "A + B → C: reasoning" for manual review
```

### Step 2: Improve the generation prompt
In `scripts/expand-recipes.ts`, revise the LLM prompt to:
- Explain *why* the combination makes sense (cause and effect)
- Be educational (teach a real fact when possible)
- Add humor that's clever, not random
- Keep it to 1 sentence, max 2
- Avoid spoiling other discoveries

**Example prompt structure:**
```
You are writing a short, witty explanation for an element combination game.
The player just combined "{A}" and "{B}" to create "{Result}".
Write ONE sentence explaining why this combination makes sense.
Be educational and funny. Don't reference the game itself.

Good: "When water meets extreme heat, it transforms into steam — basic thermodynamics with dramatic flair!"
Bad: "Fire steals the water's essence in a fiery finale of doom!" (nonsensical, not educational)
```

### Step 3: Regenerate reasonings
Run the updated pipeline:
```bash
npm run expand:recipes
npm run validate
```

### Step 4: Manual review pass
Spot-check a sample of regenerated reasonings for quality.

## Testing
1. Open Recipes Modal → verify reasonings make sense
2. Check a sample across different groups (Nature, Science, Fantasy, etc.)
3. Ensure no recipes are missing reasonings after regeneration
